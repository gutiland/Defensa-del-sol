# Casetas y presentación de atacantes

## Casetas

Las reglas de colocación y el coste se conservan; el crecimiento es visual. Las tiendas pasan de lona remendada a tienda equipada, tarima y acabados de nivel superior. La base tiene una escala algo mayor para seguir siendo reconocible. La cocina, radio y barricada también crecen con sus niveles.

La base mantiene su portavoz. Radio y cocina conservan personal visible; las tiendas lo muestran desde nivel 3. Área, olor y barricada no tienen un muñeco permanente. Los proyectiles de las construcciones sin personal salen desde la propia caseta.

Al seleccionar una construcción, mejoras, especializaciones y retirada aparecen en un panel flotante dentro del tablero. Se coloca arriba o abajo según el espacio y, en pantallas estrechas, permanece dentro del tablero con desplazamiento interno. El lateral conserva el catálogo para comprar construcciones, no los controles de mejora.

Las clases conocidas reaparecen en combinaciones posteriores. Las fichas se muestran solo al primer encuentro de cada tipo en una partida de defensa, pausan la acción y explican estadísticas y contramedidas. Si el jugador ya había pausado, cerrar la ficha mantiene esa pausa. Cada partida reinicia los descubrimientos. Admin no presenta fichas automáticas para no interrumpir pruebas.
